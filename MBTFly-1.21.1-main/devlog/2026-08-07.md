## 遇到的问题

1. **Fabric API 版本号错误**: 原定 `0.131.0+1.21.11` 不存在。通过 Fabric Maven 仓库目录列表确认 1.21.11 的最新 Fabric API 版本为 `0.141.4+1.21.11`。
2. **Loom 版本不兼容**: Loom 1.11.8 无法处理新版 Fabric API 的 javadoc 格式，报错 `Javadoc provided by mod (fabric-content-registries-v0) must be have an intermediary source namespace`。升级至 Loom 1.17.17 解决。
3. **Gradle 版本要求**: Loom 1.17 要求 Gradle 9.5+，原项目使用 Gradle 8.14.5。升级至 Gradle 9.6.1。
4. **Yarn 映射方法重命名**: `Entity.getPos()` 在 1.21.2+ Yarn 映射中重命名为 `Entity.getEntityPos()`。通过 `javap` 分析 Minecraft jar 确认。
5. **disconnect() 方法签名变更**: `ClientWorld.disconnect()` 和 `MinecraftClient.disconnect()` 在 1.21.2+ 均需要 `Text` 参数。
6. **UTF-8 BOM 编码问题**: PowerShell 脚本写入文件时添加了 BOM，导致 Java 编译器报错 `非法字符: '\ufeff'`。通过移除 BOM 字节解决。
